# Learning roadmap

Only the mass–spring–damper project is implemented.

| Subject | Proposed study | Validation target |
|---|---|---|
| Calculus / vibrations | Forced response and resonance | Steady-state amplitude and phase |
| MATLAB | Repeat free vibration using `ode45` | Initial conditions and Python comparison |
| Thermodynamics | Ideal-gas cycle with stated property assumptions | First-law balance and units |
| Fluid Mechanics | Pipe pressure drop | Limiting regimes and pressure units |
| CAD/FEA | Beam deflection study | Analytical beam solution and mesh convergence |
| Materials Science | Stress–strain data analysis | Stress units and documented fitting range |

Add each study only after it has reproducible inputs, assumptions, validation, and an interpretation of limitations.
