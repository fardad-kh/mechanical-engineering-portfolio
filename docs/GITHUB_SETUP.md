# Publish to GitHub

1. Extract the ZIP and open a terminal in `mechanical-engineering-portfolio`.
2. Review the author name, README, and source. Select a license if you want to grant reuse rights; none has been imposed.
3. Create an empty GitHub repository named `mechanical-engineering-portfolio`. Avoid adding a README when creating it.
4. Replace YOUR_USERNAME in the remote address below and run:

```bash
git init
git add .
git commit -m "Add mechanical engineering portfolio and validated vibration study"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/mechanical-engineering-portfolio.git
git push -u origin main
```

Suggested description: Undergraduate mechanical engineering portfolio with SI-based modeling, analytical validation, and Python vibration studies.

Suggested topics: mechanical-engineering, python, vibrations, numerical-methods, engineering-education.

This is a project portfolio repository. GitHub's special profile README requires a separate repository whose name exactly matches your username; you can link this portfolio from that profile.
